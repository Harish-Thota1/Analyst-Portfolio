## Featured Case Studies

### 1) Enterprise Data Platform Migration (Microsoft Fabric) — Grad Careers
**Problem:** Operational decisions were based on delayed Excel exports and inconsistent booking data.  
**Outcome:** Improved staffing forecast accuracy **65% → 85–90%**, reduced disputes **15–20 → 3–5 per cycle**, remediated **4,000+** timestamp defects across **200,000+** session records.  
**Tech:** Microsoft Fabric (Lakehouse/Warehouse), SQL/T-SQL, Python, Power BI, Power Automate

### 2) Compliance Automation Platform (Databricks) — AIML
**Problem:** High manual effort and late detection of compliance issues across finance transactions.  
**Outcome:** Reduced manual exception review from **40+ hrs → <2 hrs/month**, improved pipeline runtime **45 → 12 mins**, supported stable delivery with **99%+** availability.  
**Tech:** Databricks, PySpark, Python, SQL, Power BI

### 3) Supply Chain Analytics Suite — Hyundai Mobis
**Problem:** Slow issue resolution and manual reconciliation across procurement/warehouse workflows.  
**Outcome:** Improved supplier OTD **72% → 89%**, reduced issue resolution **2 days → 4 hours**, eliminated **8+ hrs/week** manual reconciliation.  
**Tech:** Power BI, Azure SQL, Azure Data Factory, Power Platform, SharePoint
